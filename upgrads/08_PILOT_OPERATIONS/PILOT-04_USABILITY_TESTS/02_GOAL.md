# PILOT-04: Goal and Plan

## SMART Goal

> Within **5 days**, run five moderated sessions across pilot roles and publish anonymised findings.

## Acceptance Standards

### Standard 1: Participants

- Five users.
- At least three roles: manager, reviewer, operator.
- Participant IDs only in the report.

### Standard 2: Tasks

1. Sign in and select the pilot company.
2. Create a task and assign it to a branch.
3. Review an evidence item.
4. Export a weekly report.
5. Explain how an AI suggestion is accepted or rejected.

### Standard 3: Measures

- Completion: completed / partial / failed.
- Time on task.
- Critical errors.
- Confidence rating (1-5).
- Qualitative observation.

### Standard 4: Findings

Every finding includes: ID, task, observation, evidence reference, severity, recommendation, owner, and disposition.

## Implementation Plan

### Day 1 — Protocol

- [ ] Draft script and consent.

### Days 2-4 — Sessions

- [ ] Recruit and run five sessions.
- [ ] Store notes in restricted evidence.

### Day 5 — Report

- [ ] Anonymise and prioritise findings.
- [ ] Obtain UX and Pilot Manager sign-off.

## Cancellation Criteria

- Stop a session immediately if consent is withdrawn or real customer data appears.
