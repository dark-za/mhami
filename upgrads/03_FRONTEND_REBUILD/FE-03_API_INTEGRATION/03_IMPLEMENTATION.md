# FE-03: OpenAPI Types Integration — Implementation

## Files added
- `frontend/src/api/typed.ts` — type-safe wrappers (`getTaskInstance`,
  `listTasks`, `listEvidence`).
- `frontend/src/api/typed.test.ts` — unit tests for the wrappers.

## Files changed
- `frontend/scripts/check-generated-types.mjs` — now also verifies
  that the workspace-critical paths are exposed in the generated file.
- `frontend/package.json` — keeps the `prebuild`, `predev`, and
  `pretest` scripts wired to the check script.

## Approach
1. The schema is generated by `openapi-typescript` against a live
   backend (`npm run generate:api`).
2. `src/api/typed.ts` re-uses the `components` types from
   `generated-types.ts` to provide ergonomic wrappers for the most
   common workspace calls.
3. `scripts/check-generated-types.mjs` is invoked by every build, dev,
   and test step so a missing or stale file fails fast.
