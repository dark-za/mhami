# API Error Codes

## Platform (PLATFORM)
- `PLATFORM-001`: Internal Server Error.
- `PLATFORM-002`: Validation Error.
- `PLATFORM-003`: Unauthorized.
- `PLATFORM-004`: Permission Denied.
- `PLATFORM-005`: Not Found.

## Tasks (TASK)
- `TASK-001`: Invalid transition.
- `TASK-002`: Task is already completed.
- `TASK-003`: Invalid recurrence schedule.

## Evidence (EVIDENCE)
- `EVIDENCE-001`: Invalid evidence type.
- `EVIDENCE-002`: Session expired.
- `EVIDENCE-003`: File format not supported.

## Backups (BACKUP)
- `BACKUP-001`: Backup run not found.
- `BACKUP-002`: Cannot restore from a failed backup.

## Auth & Identity (AUTH)
- `AUTH-001`: Invalid credentials.
- `AUTH-002`: Account disabled.

## Organizations & Tenancy (TENANT)
- `TENANT-001`: Cannot demote owner.
- `TENANT-002`: Organization limit reached.
