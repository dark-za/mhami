# Governance

## Purpose

Define the repository and change-control model for the project.

## Source of Truth

- `docs/PROJECT_CHARTER.md`
- `docs/CONSTITUTION_AMENDMENTS.md`
- `docs/REQUIREMENTS_BASELINE.md`
- `docs/ARCHITECTURE_BASELINE.md`
- `docs/SECURITY_AND_DATA_BASELINE.md`
- `docs/DELIVERY_ROADMAP.md`
- `docs/phases/`
- `docs/adr/`

## Rules

- Phase documents are release gates.
- The baseline may only change through documented review.
- Foundational changes require an ADR.
- Runtime decisions cannot silently override approved documentation.
