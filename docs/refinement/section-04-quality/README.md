# القسم الرابع: الجودة والاختبار (Quality & Testing)

> **المراحل:** R-09 → R-10
> **المدة المقدرة:** 1-2 يوم
> **الأثر:** ~−700 سطر (كود ميت + setup مكرر)
> **المخاطرة:** 🟢 منخفضة

## فلسفة القسم

تنظيف **كل ما لا يضيف قيمة**:
- كود ميت (imports, functions, fields لا تُستخدم)
- setup مكرر في الاختبارات
- fixture boilerplate

## القاعدة الذهبية

> **كل اختبار يجب أن يصف ما يختبره، لا كيف يُنشئ بياناته**
