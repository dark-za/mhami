# Contributing

## Status

This repository contains a runnable Mhami foundation. Contributions should keep the codebase stable, auditable, and easy to operate.

## Rules

- Follow the documented change-control process for security, tenancy, AI, legal, evidence, backup, and deployment changes.
- Keep implementation changes small enough to review and test.
- Keep secrets out of Git.
- Use an ADR for any foundational or hard-to-reverse decision.
- Use small, reviewable commits with a clear subject.
